Training Curriculum

A 4-session training course (3 hours each) — total 12 hours — with an optional 1-hour showcase at the end.

Foundation Phase

session 1

Build the frontend with HTML, TailwindCSS, and JavaScript fundamentals.

In Scope

  • HTML5 semantic structure
  • TailwindCSS utility classes
  • JavaScript DOM manipulation
  • Mobile-first responsive design

Out of Scope

  • Advanced frameworks (React, Vue, Angular)
  • Complex CSS pre-processors (Sass/Less)

Integration Phase

session 2-3

Connect your frontend to a Google Sheets backend using Google Apps Script.

In Scope

  • Google Apps Script basics
  • Creating simple APIs
  • Sending data to Sheets
  • Basic Email Automated Notifications

Out of Scope

  • Advanced database systems (MySQL, PostgreSQL)
  • Complex API authentication (OAuth)

Deployment Phase

session 4

Deploy your application and implement best practices for production.

In Scope

  • GitHub version control
  • Vercel deployment
  • GitHub Pages setup
  • Basic SEO setup (meta tags, titles, descriptions)

Out of Scope

  • Enterprise-level SEO audits
  • Paid advertising and marketing campaigns

Frequently Asked Questions

Everything you need to know about the training course

What if I've never make a project before?

No problem! This Training Course is designed for beginners and Intermediate level. You'll learn how to link the dots step by step—from your knowledge of HTML to deployment. We start with the fundamentals and build up to more complex concepts at a comfortable pace.

How do I connect my web app to Google Sheets?

You'll use Google Apps Script to create a simple API that fetches data from your sheet. We cover this during the Integration Phase, Setting up your backend and connecting it to your frontend. Including troubleshooting common issues

Where do I deploy my final project?

You can deploy on Vercel or GitHub Pages—both are free and beginner-friendly. We provide detailed walkthroughs for both platforms during the Deployment Phase, with step-by-step guidance on deploying your frontend.

What's the time commitment for this training course

The training course is designed to be completed in 4 sessions with about 12 hours of commitment in total. However, you'll have lifetime knowledge, so you can learn as you go.
